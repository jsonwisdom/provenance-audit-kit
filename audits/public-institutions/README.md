# Public Institution Replay Audits

Institution-specific evidence lives below this directory. Shared protocol logic lives under `protocols/public-replay/v0.1/`.

```text
audits/public-institutions/
  ssa/
  white-house/
  <future-institution>/
```

Each corpus owns its own scope, raw evidence, manifest, receipts, knowledge graph, and optional witness bindings.

```text
COMMITTER != SOURCE != IMPLEMENTER
```

No institution inherits authority from another institution merely because both use the same verifier.
